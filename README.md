# P13 – The Aesthetics of Generation

University project for the NLP course (Università degli Studi di Milano).
Research question: **do large language models have a recognisable stylistic fingerprint?**

I generated a controlled corpus with four LLMs (Llama 3.3 70B, Mistral Large, GPT-OSS 20B and Qwen3 32B) on four genres
(narrative, argumentation, dialogue and description), extracted stylometric features with
[StyloMetrix](https://github.com/ZILiAT-NASK/StyloMetrix) and analysed them with unsupervised and supervised methods.

> **The report to read is [`report.pdf`](report.pdf).** It describes the corpus, the methods and all the results.
> The two notebooks contain the code that produces them.

## Main results

- **Unsupervised:** PCA, t-SNE, UMAP and K-Means group the texts by genre (ARI ≈ 0.98) and not by model (ARI ≈ 0). The genre dominates the variance.
- **Supervised:** a Random Forest on 163 stylometric features recognises the model with 89.9% accuracy in grouped cross-validation and
  **93.1% on a test set of unseen prompts** (149/160, 95% CI 88.1–96.1%; chance is 25%). With only the 40 most important features it reaches 90.0%.
- **Tone masks** (Hemingway, academic, casual, Gen Z): the accuracy falls to 70.3% but stays far above chance.
- **Imitation between models** (2 example texts in the prompt): the imitator is fooled in 3–22% of the texts in three pairs out of four, and in 53% for GPT-OSS imitating Qwen.

## Repository structure

| Path | Content |
|---|---|
| `report.pdf` | the report of the project |
| `01_analisi_stilometrica.ipynb` | training corpus, PCA / t-SNE / UMAP, K-Means (ARI), Random Forest with cross-validation and test set |
| `02_robustezza.ipynb` | final model (top 40 features), tone masks and imitation between models (stress tests) |
| `src/` | functions used by the notebooks (feature extraction, preprocessing, Random Forest, feature importance, model saving) |
| `generazione_dataset/` | scripts and prompts (JSON) used to generate the corpora; see its own README |
| `corpus_training*.csv`, `test_set*.csv`, `masked_test_set*.csv`, `cross_model_test_set_full*.csv` | generated texts and their stylometric features |
| `models/` | saved classifier (`rf_top40_*`, joblib, scikit-learn 1.8.0) |
| `.env.example` | names of the API keys needed to regenerate the texts (copy it to `.env` and fill it in) |

## How to run

```bash
pip install -r requirements.txt
jupyter notebook 01_analisi_stilometrica.ipynb
```

The CSV files already contain the generated texts and the extracted features, so the notebooks run without any API key.
Regenerating the texts needs `GROQ_API_KEY` and `MISTRAL_API_KEY`, and it is not guaranteed to work: the project was done in May 2026
and some of the original models (Llama 3.3 70B and Qwen3 32B on Groq) are no longer available.
